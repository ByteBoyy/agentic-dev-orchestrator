# Task brief: make agent orchestration inspectable

## Outcome

Create a dedicated repository and project-level instruction pattern that demonstrate planning, bounded delegation, review, and shipping workflows for an AI-native engineering application.

## In scope

Current official conventions for `CLAUDE.md`, `AGENTS.md`, skills, subagents, and living plans; a dedicated public-ready orchestration repository; truthful documentation tied to real projects.

## Out of scope

Fabricated historical usage, fake commits, broad product refactors, automatic deployment, and unapproved GitHub account changes.

## Acceptance

A reviewer can identify the source of truth, invoke named workflows, inspect constrained roles, follow a living plan, and distinguish observed evidence from claims.

## Constraints and risks

Claude Code is not installed in the current environment, so runtime invocation must be marked not run. GitHub CLI is not authenticated, so remote creation requires a later authentication/approval step.

## Human approvals required

Repository name/publication, push, account profile edits, pins, merge, and deployment.
